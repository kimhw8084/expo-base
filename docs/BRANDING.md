# Branding and white-label contract

Product branding is configuration, not a component fork.

`PrecisionBrand` explicitly defines a light and dark semantic accent palette. The platform applies it to:

- primary/hover/pressed interaction colors
- foreground-on-primary color
- subtle interaction surfaces
- focus indication
- primary visualization series

Dark mode is never automatically generated by inverting or lightening one product hex value.

Built-in starter presets: `blue`, `violet`, `green`, `orange`.

A generated app owns `brand.ts` and can replace the preset with an approved custom pair. Components continue consuming semantic tokens and require no edits.
